# Designer Skills Reference Set

This directory contains the upstream Markdown references used by the project-local
`designer-frontend` Codex skill. It was copied from:

<https://github.com/Owl-Listener/designer-skills>

Source revision: `20e34c4a587e5eb09fcdf8351fa97b3ad761b31e`

The selected collections are:

- `ui-design`: layout, color, typography, responsive behavior, and visual hierarchy
- `visual-critique`: review of existing screens across seven visual dimensions
- `design-systems`: tokens, components, accessibility, theming, and motion governance
- `interaction-design`: states, feedback, loading, errors, micro-interactions, and animation
- `prototyping-testing`: heuristic evaluation, accessibility testing, and test planning
- `design-ops`: handoff, design QA, review process, and design debt

The upstream files are guidance for Codex, not application runtime code. Read only the
specific reference needed for the current UI task. The upstream license is preserved in
this directory.
