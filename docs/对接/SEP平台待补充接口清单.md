## 二、首页缺少组织架构及企业员工统计

### 1. 组织架构查询

**缺少内容：**企业部门、真实成员、负责人，以及成员可使用的硅基员工之间的关联。

**需要的操作：**开放组织架构只读查询，返回真实组织与有效授权数据。

**接口要求：**建议 `GET /enterprise/organization`，也可复用已有部门、成员、授权查询接口。需要提供：

| 数据 | 必要内容 |
|---|---|
| 部门 | `id`、`name`、`parentId`、`leaderId`、`sortOrder` |
| 成员 | 成员 `id`、`userId`、展示姓名、`departmentId`、`position` |
| 负责人/汇报关系 | 真实部门负责人；若支持个人直属上级，返回其真实关联，不以部门上下级冒充个人汇报关系 |
| 有效员工授权 | `subscriptionId`、授权的 `memberId` 或 `departmentId`、`expiresAt`，说明部门授权继承规则 |
| 硅基员工 | 对应的 `employeeId`、`subscriptionId`、姓名、头像、职责及状态 |

需明确普通成员和管理员分别可以查看哪些组织数据。

### 2. 企业员工目录与统计

**缺少内容：**企业硅基员工总数、企业员工列表、当前用户可使用数量。现有 `/client/subscriptions` 仅代表当前用户的可用订阅，不能代表企业全部员工。

**接口要求：**可合并进组织架构查询，也可开放独立查询（建议 `GET /enterprise/overview`）。返回上述数据，明确总数按员工去重还是按订阅计数，以及是否包含停用、过期订阅。已有员工状态 HTTP/WS 接口继续复用。

## 三、Skill 缺少个人修改版本上传与审核结果查询接口

**操作流程：**用户查看并修改完整 `SKILL.md` 原文 → 点击保存时同步发起上传 → 平台接收个人修改版本并进入审核流程 → 用户可查询审核状态、结果及原文。不是先保存后再由用户另点“提交审核”。

上传的是完整 Markdown 原文，包括 frontmatter，不是拆分后的表单字段；创建个人版本，不覆盖原发布版本。

### 1. 保存时上传并提交审核

**需开放接口：**建议 `POST /enterprise/skill-versions`，Bearer 登录认证。

请求内容示例（字段沿用平台模型）：

```json
{
  "capabilityId": "对应的技能能力ID",
  "parentVersionId": "本次修改所基于的版本ID",
  "content": "完整的 SKILL.md 原文",
  "changeSummary": "本次修改说明（可选）"
}
```

接口行为要求：

- 根据登录身份确定 `ownerId`、`enterpriseId`，校验来源版本与能力的关联和访问权限。
- 创建 `PERSONAL` 修改版本并提交管理员审核；成功响应必须表示已进入待审核状态，不能只上传文件或只创建未提交的草稿。
- 返回 `id`、`capabilityId`、`parentVersionId`、`scope`、`version`、`status`、`submittedAt`，用于查询后续审核结果。
- 版本号由平台生成或明确生成规则；提供幂等重试机制，同一次保存因网络重试不得重复创建版本或审核单。
- 提交后的原文固定；再次修改保存产生新的待审核版本，不改写正在审核或已通过的版本。
- 如果已有接口分为“创建版本”和“提交审核”，请提供两者及失败重试规则，确保同一次用户保存即可完成上传和送审。

### 2. 查询个人版本及审核结果

**需开放或扩展接口：**优先扩展现有 `GET /enterprise/employees/:employeeId/skills` 的 `versions`；如需独立查询，建议 `GET /enterprise/skill-versions?capabilityId=...`。

需返回当前用户可用的发布版本，以及本人提交的个人版本（包括待审核、通过、驳回），提供：

- `id`、`capabilityId`、`parentVersionId`、`scope`、`version`。
- `status`、`submittedAt`、对应审核时间、`rejectionReason`。
- 明确哪些状态允许选择使用；说明 `currentVersion`、`upgradeAvailable` 的含义和最新已发布版本的识别方式。

必须能查询到审核状态变化；查询接口即可满足本期需求，不强制新增审核通知 WS。

### 3. 读取指定版本完整原文

**现有接口：**`GET /enterprise/skill-versions/:versionId/preview`。

**需确认或补齐：**`content` 返回完整、未截断的 Markdown 原文，保留 frontmatter 和换行；支持按权限读取发布版及本人各审核状态的个人版本。只返回渲染预览或摘要不能满足原文编辑需求。
