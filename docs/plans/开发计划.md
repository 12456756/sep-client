## 认证架构总览（重要）

SEP 使用**三层 Token 架构**，不是传统的 OAuth：

| Token 类型 | 用途 | 有效期 | 获取方式 | 存储位置 |
|-----------|------|--------|---------|---------|
| 通用 accessToken | 获取实例列表 | 1小时 | 邮箱密码登录 | 内存 |
| refreshToken | 换取实例令牌 | 30天 | 邮箱密码登录 | safeStorage 加密 |
| 实例级 accessToken | 调用 AI 网关 | **15分钟** | refreshToken + instanceId | 内存 |

**关键点**:
- 实例级 token 只有 15 分钟，需要主动预刷新（提前 5 分钟）
- 用户登录后需要**先选择 AI 实例**，然后才能开始对话
- `before_provider_headers` 中必须注入实例级 token，不能用通用 token

**实现方法**（基于 SEP API v1.0）:

1. **设备指纹生成**
   ```typescript
   // electron/device-fingerprint.ts
   import crypto from 'crypto';
   import os from 'os';
   
   export function generateDeviceFingerprint(): string {
     const data = [
       os.hostname(),
       os.platform(),
       os.arch(),
       os.cpus()[0]?.model || 'unknown',
     ].join('|');
     
     return crypto.createHash('sha256').update(data).digest('hex').substring(0, 64);
   }
   ```
   - 同一台设备每次启动返回相同值
   - 首次生成后存储在 `electron-store`，持久化复用

2. **登录 API 调用**
   ```typescript
   // electron/auth-api.ts
   async function login(req: LoginRequest): Promise<LoginResponse> {
     const response = await fetch(`${SEP_BASE_URL}/client/auth/login`, {
       method: 'POST',
       headers: { 'Content-Type': 'application/json' },
       body: JSON.stringify({
         email: req.email,
         password: req.password,
         fingerprint: req.fingerprint,
         platform: process.platform,
         clientVersion: app.getVersion(),
       }),
     });
     
     if (!response.ok) {
       const error = await response.json();
       throw new Error(error.message || 'Login failed');
     }
     
     return response.json();
   }
   ```

3. **Token 安全存储**
   - 使用 `electron.safeStorage` 加密存储 refreshToken
   - accessToken (通用) 存内存，不落盘

### 3. 实例级 Token 自动刷新

**优先级**: P0  
**阻塞关系**: 阻塞长时间对话  
**依赖**: 实例选择完成

**实现方法**:

```typescript
class InstanceTokenManager {
  private instanceToken: string | null = null;
  private expiresAt: number = 0;
  private refreshTimer: NodeJS.Timeout | null = null;
  private readonly REFRESH_BEFORE_MS = 5 * 60 * 1000;
  
  async initialize(refreshToken: string, instanceId: string) {
    const { accessToken, expiresIn } = await getInstanceToken({
      refreshToken,
      instanceId,
    });
    
    this.instanceToken = accessToken;
    this.expiresAt = Date.now() + expiresIn * 1000;
    this.scheduleRefresh();
  }
  
  private scheduleRefresh() {
    if (this.refreshTimer) clearTimeout(this.refreshTimer);
    
    const delay = Math.max(0, this.expiresAt - this.REFRESH_BEFORE_MS - Date.now());
    
    this.refreshTimer = setTimeout(async () => {
      try {
        await this.refreshNow();
      } catch (error) {
        mainWindow?.webContents.send('auth:token-expired');
      }
    }, delay);
  }
  
  getValidTokenSync(): string {
    return this.instanceToken!;
  }
}
```

**集成到 pi-coding-agent**:
```typescript
const providerExtension: ExtensionFactory = (pi) => {
  pi.on('before_provider_headers', (event) => {
    const token = tokenManager.getValidTokenSync();
    event.headers['authorization'] = `Bearer ${token}`;
  });
};
```

**验收标准**:
- [ ] 对话超过 10 分钟，token 自动刷新

### 5. 工具调用权限审批

**优先级**: P0  
**依赖**: pi Session 完成

**实现方法**:

```typescript
class ApprovalManager {
  private pendingRequests = new Map();
  
  async requestApproval(event: ToolCallEvent): Promise<ToolCallEventResult> {
    const requestId = crypto.randomUUID();
    
    mainWindow.webContents.send('tool-approval:request', {
      requestId,
      toolName: event.name,
      args: event.args,
    });
    
    return new Promise((resolve) => {
      const timeout = setTimeout(() => {
        this.pendingRequests.delete(requestId);
        resolve({ block: true, reason: 'timeout' });
      }, 60_000);
      
      this.pendingRequests.set(requestId, { resolve, timeout });
    });
  }
  
  handleUserResponse(requestId: string, approved: boolean) {
    const pending = this.pendingRequests.get(requestId);
    if (!pending) return;
    
    clearTimeout(pending.timeout);
    this.pendingRequests.delete(requestId);
    
    pending.resolve(
      approved ? { block: false } : { block: true, reason: 'user denied' }
    );
  }
}
```

**Extension 集成**:
```typescript
const guardExtension: ExtensionFactory = (pi) => {
  pi.on('tool_call', async (event): Promise<ToolCallEventResult> => {
    if (['bash', 'write', 'edit'].includes(event.name)) {
      return await approvalManager.requestApproval(event);
    }
    return { block: false };
  });
};
```

**验收标准**:
- [ ] AI 调用 bash/write/edit 时弹出审批对话框
- [ ] 用户允许后工具执行成功
- [ ] 用户拒绝后 AI 收到拒绝通知

### 6. 流式消息 UI 渲染

**优先级**: P0  
**依赖**: pi Session 完成

**实现方法**:

1. **RAF 批量更新**
   ```typescript
   let pendingUpdate: string | null = null;
   let rafId: number | null = null;
   
   const appendChunk = (chunk: string) => {
     pendingUpdate = (pendingUpdate || '') + chunk;
     
     if (rafId === null) {
       rafId = requestAnimationFrame(() => {
         if (pendingUpdate) {
           setMessages(prev => {
             const last = prev[prev.length - 1];
             return [
               ...prev.slice(0, -1),
               { ...last, content: last.content + pendingUpdate }
             ];
           });
           pendingUpdate = null;
         }
         rafId = null;
       });
     }
   };
   ```

2. **条件 Markdown 渲染**
   - 流式传输中: 渲染为 `<pre>` 纯文本
   - 流式完成后: 解析 Markdown + 代码高亮

3. **React.memo 隔离**
   ```typescript
   const MessageItem = React.memo(({ message }) => {
     if (message.streaming) {
       return <pre className="whitespace-pre-wrap">{message.content}</pre>;
     }
     return <ReactMarkdown>{message.content}</ReactMarkdown>;
   });
   ```

### 11. electron-builder 打包配置

**跨平台配置**:
```json
{
  "build": {
    "appId": "com.sep.client",
    "productName": "SEP Client",
    "mac": {
      "target": ["dmg", "zip"],
      "hardenedRuntime": true,
      "entitlements": "build/entitlements.mac.plist"
    },
    "win": {
      "target": ["nsis"],
      "certificateFile": "${env.WINDOWS_CERT_FILE}"
    },
    "linux": {
      "target": ["AppImage", "deb"]
    }
  }
}
```

**代码签名**:
- macOS: Apple Developer Program + Developer ID + 公证
- Windows: Authenticode 证书 (.pfx)

### 12. electron-updater 自动更新

- 使用 GitHub Releases 作为更新服务器
- macOS 更新用 `.zip` 格式（不是 `.dmg`）
- 启动后延迟 3 秒检查更新
- 下载完成后提示用户重启

### 13. GitHub Actions CI/CD

- 多平台构建矩阵: `[macos-latest, windows-latest, ubuntu-latest]`
- 推送 `v*.*.*` tag 自动触发
- 自动签名 + 公证 + 发布到 GitHub Releases

**所需 Secrets**:
- `APPLE_CERTIFICATE` (Base64)
- `APPLE_ID` / `APPLE_ID_PASSWORD` / `APPLE_TEAM_ID`
- `WINDOWS_CERT_FILE` / `WINDOWS_CERT_PASSWORD`
