## 已实现

| 文件组 | 行为 |
| --- | --- |
| `src/shared/skill-import-contracts.ts`、fixture、`electron/domain/skill-import*` | 协议 v1 的 Zod 边界、签名和范围摘要、状态与端口；与实际 SEP fixture 对齐 |
| `electron/common/skill-import-link.ts`、`bootstrap/skill-import-deep-link.ts`、`main.ts` | 严格解析 `sep-import`、可信实例白名单、早期冷启动队列、单实例；仅需本机处理时显示和聚焦 |
| `electron/common/platform/skill-import-api.ts` | 独立 HTTPS 设备协议、禁止重定向、响应预算、超时与取消、流式 multipart；不使用业务登录凭据 |
| `electron/data/skill-import-device-store.ts`、`bootstrap/create-skill-import.ts` | safeStorage 加密与原子持久化、实例/设备/操作系统用户隔离、临时授权降级、待撤销记录 |
| `electron/data/skill-import-files.ts` | Agent 目录与原生授权项目、canonical root 去重、分阶段读取、预算、快照、哈希、流式 ZIP、过期清理 |
| `electron/service/skill-import-service.ts` | 首次两端确认、记住范围复用、命令/事件幂等、grant 续期、远端取消、上传结果回查与同包重试 |
| `controller/routes/skill-import.ts`、preload、channels、renderer bridge | 可信主 frame 的窄 IPC、安全状态快照、订阅与渲染器恢复；不暴露路径或 grant |
| `src/pages/SkillImportPage.tsx`、hook、样式、App | Web 唤起的免业务登录授权页、配对码、范围选择、取消、设备授权撤销与更新入口；保留已挂载业务视图；登录页及账户菜单不提供导入入口 |
| backend 装配、窗口/停机、updater、builder 配置及测试 | 应用退出和更新包含导入清理；业务登出保持独立；更新安装检查导入任务；同一安装包声明协议 |

扫描与打包覆盖中文路径、多行 YAML、合法隐藏资源和 `.env.example`、获准根内的文件/目录链接、空目录，以及预览后文件或目录变化。目录链接保留链接处相对名称；改名链接指向真实秘密文件仍阻断。排除缓存或依赖目录时返回预览警告；元数据缺失或不规范时提供可预览候选与警告，由后端作最终格式判断。

候选 ID 每次扫描随机生成；根 ID 用于保存授权。秘密正文、设备私钥、session/upload grant 和绝对路径不进入 renderer 状态。预览只读取选中技能，上传只使用已经确认的快照；不执行或修改源文件。

## Web 唯一入口调整与验证

根据用户对初版体验的反馈，本轮移除了登录页“本机 Skills 导入，无需登录”和账户菜单“本机 Skills 导入”，以及相关 prop 传递。生产界面不增加隐藏快捷键；诊断可通过现有开发调试连接执行内部 IPC。

- 右侧空白由初版 UI 脚本在真实 Electron 上遗留 `960px` 视口模拟造成，原生窗口宽度为 `1200px`。已清除模拟；真实窗口验证脚本不再改变视口，并在 `finally` 中清理模拟和恢复页面显隐。
- Web 发起连接时保持工作区显示；先验证记住的设备、账号和原授权根范围，验证成功则扫描、预览、打包、上传全程在后台执行。普通失败、完成和运行中重复唤起不抢焦点。
- 首次授权、授权失效或范围不匹配时展示本机确认；确认通过后返回原工作区，继续在 Web 操作。新增目录仍通过原生目录选择与明确授权处理，不扩大记住的根范围。

## 联调与发布门禁

1. 相邻 SEP 后端默认 `SKILL_IMPORT_MIN_CLIENT_VERSION=1.0.0`，当前客户端为 `0.3.3`。内测需由后端配置与待验收客户端版本对齐，发布时再确定正式最低版本；本任务没有擅自修改版本号或生产配置。
2. 后端须启用 `SKILL_IMPORT_ENABLED`，`SKILL_IMPORT_INSTANCE_ID` 与本机可信实例一致。客户端默认 `sep-default` 映射到发行配置中的 HTTPS API；私有内测通过本地 `SEP_SKILL_IMPORT_INSTANCES` JSON 配置，不允许深链接指定 API URL。
3. 尚未执行真实 HTTPS 站点的 Web ADMIN 发起、两端确认、扫描、预览、上传、创建待审核能力的完整流程。包解析往返和源码契约复核不能替代该验收。
4. 尚未生成或安装正式签名 Windows x64、macOS arm64/x64 包。系统协议冷/热启动、NSIS 卸载、路径含空格、Keychain、跨版本升级与 Windows junction/盘符矩阵仍须实机验证。
5. Linux 仅保留已有 AppImage 配置和 basic_text 持久化阻断，本期不声明其导入唤起可发布。

当前开发进程为 `npm run dev:debug`，renderer 地址 `http://localhost:5173/`，Electron 调试端口 `9333`。真实主进程/IPC 功能应在 Electron 窗口中体验。
