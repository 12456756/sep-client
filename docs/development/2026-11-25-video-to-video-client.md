# 视频生视频客户端接入

基于 SEP `2026-11-24-video-to-video-implementation.md` 接入 V3 视频生视频。

## 用户操作

- 已有对话的输入区提供“参考视频 / 导入视频”，仅在当前员工获准使用 `video_from_video` 时显示。
- 可多选 MP4、MOV。数量、单文件大小、MIME 按所选 Profile 下发值限制，同时遵循 10 个、90 MiB 的协议上限。
- 原视频先保存在本机，再逐个上传。列表显示进度、失败原因，可取消上传、重试、移除。
- 数量、大小和格式说明放在导入按钮的悬停提示中。
- 同一任务切换员工后保留本地原视频；SEP 上传凭证按订阅、Profile、配置版本隔离。

## 执行和恢复

- 模型通过 `video_get_job({})` 查询 `referenceVideos`，用有序 `localVideoAssetIds` 调用 `video_from_video`。
- 真实文件路径、SEP referenceId、上传凭证、哈希不会暴露给模型或渲染层。
- 单文件使用原生文件 Blob 和 multipart 流上传，不把多个大视频整体读入内存，不手写 multipart boundary。
- 上传回执校验 Profile、配置版本、MIME、大小、SHA256 和有效期后才保存。
- 报价、提交使用同一有序 `videoReferenceIds` 和冻结的规格，保留 `audio: false`。不支持图片和视频混合参考。
- 发送前持久化 clientRequestId；断连或重启后按原请求 / 回执查询。上传失败不创建生成记录，不推断为生成提交不明。
- 已提交任务恢复不需要重新上传参考视频；下载复用原视频流程，校验大小和 SHA256 后才标为已保存。
- 同一轮相同工具调用复用原任务。正在进行的同配置上传可由生成流程共同等待，不重复上传。
- 编排可使用本任务已导入的参考视频；自动将前置节点视频成果转为参考视频不在本次接入范围。

## 验证

- 共享能力 / 请求契约、文件存储与账号隔离、IPC、本地 HTTP 全链路、工具授权与回执裁剪、断连恢复与去重、上传取消。
- 桌面和窄屏 Playwright：上传、进度、移除、长文件名布局。
- Electron 33.4.11 / Node 20.18.3 文件 Blob + multipart 流上传。
- 构建、边界检查、并发回归和 POC 01–04 通过。
- 前端类型检查通过；完整类型检查仍有原有 Playwright BrowserContext 类型冲突。全量 lint 仍有无关历史错误，定向 lint 通过。
