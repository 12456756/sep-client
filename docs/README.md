| 标记 | 含义 |
|------|------|
| **基线** | 权威文档。代码、接口、数据结构与测试必须以它为准，与它冲突的一律以它为准 |
| **在建** | 正在执行的方案，内容会变，但方向有效 |
| **参考** | 内容仍然正确，可以查，但不是决策依据 |
| **历史** | 已被取代。只用于追溯"当时为什么这么做"，**不要照它写代码** |

1. 新文档必须同时在本索引登记一行，并标状态。

3. 不写进度类文档。进度由 git log 和分支状态反映。
4. 只有 `architecture/` 和 `对接/` 里的文档可以标"基线"，且同一范围只能有一份基线。
