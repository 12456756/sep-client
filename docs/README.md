# sep-client 文档目录

## 目录结构

| 目录 | 说明 |
|------|------|
| `architecture/` | 架构设计文档 |
| `plans/` | 开发计划、roadmap |
| `progress/` | 每日/每周开发进展记录 |
| `research/` | 技术调研文档 |
| `status/` | 项目状态、里程碑追踪 |
| `对接/` | 交接文档、协作接口说明 |

- 文件名使用中文或英文 + 日期前缀（如 `2026-07-30-poc-validation.md`）
- 架构文档放 `architecture/`
- 每日进展记录放 `progress/` 并以日期命名
- 跨项目协作接口文档放 `对接/`
