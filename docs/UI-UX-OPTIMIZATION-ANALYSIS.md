- 主色: 蓝紫 (#6366f1) - 用于正在进行、操作按钮

- ❌ 无障碍对比度标注不明确
- ❌ 两个根 CSS (index.css / enterprise.css) 变量不统一

## 📐 布局优化机会

### 1. Electron 窗口集成 ⚠️ 需改进

**现状**:
- 顶部 44px 留给 Windows 窗口按钮
- 左侧 232px 固定导航
- 标题栏和内容分离

**问题**:
- ❌ macOS 红绿黄关闭按钮位置不清楚
- ❌ 小窗口时导航挤压内容
- ❌ 全屏时标题栏浪费空间
- ⚠️ 窗口拖拽区交互不明显

**优化方案**:
```
macOS: 标题栏集成到导航背景，按钮浮在右上
Windows: 标题栏在顶部，按钮右对齐
小窗口 (<800px): 导航收起成图标栏
```

### 2. 响应式布局 ⚠️ 不完整

**现状**:
- 员工列表支持卡片/列表两种视图
- 员工墙有最小卡片宽度约束

**问题**:
- ❌ 960px 以下适配缺失
- ❌ 平板竖屏 (600-900px) 无专用布局
- ❌ 某些模态框宽度固定，不响应窗口
- ⚠️ 左侧导航不能折叠

**优化方案**:
```
断点规划:
- 1400px+: 双栏(导航 + 内容 + 侧板)
- 960-1400px: 三栏全显示
- 768-960px: 导航可折叠，模态框适配
- <768px: 导航抽屉化，单栏内容
```

### 3. 内容间距和对齐 ⚠️ 不一致

**问题**:
- ❌ 页面顶部距离不统一 (有时 0，有时有 gap)
- ❌ 卡片内边距不一致
- ❌ 搜索框和筛选器间距变化
- ⚠️ 内容最大宽度无限制，大屏幕信息散乱

**优化方案**:
```
- 建立「页面内边距」规范: 16px / 24px / 32px
- 建立「最大内容宽度」: 1600px (content area)
- 统一「卡片内边距」: 12px / 16px / 20px
```

## 🎨 深色模式 ❌ 缺失

**现状**: 完全没有支持

**建议方案**:

1. **颜色映射**:
```css
/* 浅色模式 (当前) */
--ent-canvas: #f7f8fc;           /* 浅灰蓝 */
--ent-panel: #ffffff;            /* 纯白 */
--ent-ink: #20232b;              /* 深灰 */

/* 深色模式 (新增) */
@media (prefers-color-scheme: dark) {
  --ent-canvas: #1a1c2e;         /* 深蓝灰 */
  --ent-panel: #262b3d;          /* 深卡片 */
  --ent-ink: #f5f5f5;            /* 浅文字 */
  /* 其他颜色自动反转 */
}
```

2. **优先级**:
   - 第一步: 自动跟随系统偏好 (prefers-color-scheme)
   - 第二步: 在设置里添加「深色/浅色/自动」切换
   - 第三步: 保存用户偏好到 electron-store

## ♿ 无障碍访问 ⚠️ 部分实现

**已有的好实践**:
- ✅ 使用语义 HTML (`<button>`, `<label>`)
- ✅ 有 `aria-label` 和 `aria-hidden`
- ✅ 焦点可见样式 (focus-visible)

**缺失的**:
- ❌ 色彩对比度不符合 WCAG AA (某些小字)
- ❌ 没有跳转链接 (Skip to content)
- ❌ 键盘导航不完整 (Tab 顺序不理想)
- ❌ 屏幕阅读器测试未做
- ❌ 表单错误提示不明确

**优化建议**:
```
优先级 1 (必做):
  - 检查色彩对比度，修复不符合的
  - 补全 aria-label / aria-describedby
  - 确保所有交互元素都可键盘访问

优先级 2 (应做):
  - 添加跳转链接
  - 优化 Tab 顺序
  - 测试屏幕阅读器
```

## 📱 特定页面优化建议

### HomePage (首页/员工概览)

**现状**: ✅ 设计很好
- 三段式布局清晰
- 员工墙交互有趣
- 派活框快捷方便

**优化机会**:
- ⚠️ 员工很多时，转圈过快，难以找人 → 添加搜索/跳转
- ⚠️ 派活后没有反馈 → 显示「已发送」提示
- ❌ 小窗口时员工墙无法使用 → 降级为列表

### EmployeesPage (员工列表)

**现状**: ✅ 功能完整
- 搜索/筛选工作
- 卡片/列表两种视图
- 虚拟滚动优化

**优化机会**:
- ⚠️ 搜索框太小，不明显 → 突出显示
- ⚠️ 筛选器隐藏，容易漏掉 → 显示活跃筛选
- ❌ 小窗口时按钮排成一行，太挤 → 改为下拉菜单

### WorkRecordsPage (工作记录)

**现状**: ⚠️ 功能复杂
- 5 种分类 (全部/进行中/需要我处理/已完成/未完成)
- 搜索 + 详情抽屉
- 删除/终止操作需二次确认

**优化机会**:
- ⚠️ 分类太多，选项卡超宽 → 改为下拉菜单 (小屏幕)
- ⚠️ 右侧抽屉占一半屏幕 → 改为模态框 (小屏幕)
- ❌ 操作按钮小且易误触 → 增大交互区域

### ArrangeWorkPage (安排工作)

**现状**: ✅ 三种模式清晰
- 对话式
- 自动编排
- 自己编排

**优化机会**:
- ⚠️ 三张卡片并排，卡片容易挤压 → 响应式显示
- ❌ 设置抽屉可能被覆盖 → 改为模态框
- ⚠️ 返回按钮位置不明显 → 突出显示

## 🎬 微交互和动画

### 现状

**已实现**:
- ✅ 标题栏拖拽
- ✅ 员工墙左右转圈
- ✅ 按钮 hover 效果

**缺失**:
- ❌ 页面切换转换不明显
- ❌ 表单验证反馈动画缺失
- ❌ 列表项删除没有退出动画
- ❌ 加载进度没有动画表现

### 优化建议

```css
/* 建立动画规范 */
--motion-fast: 120ms;           /* UI feedback */
--motion-normal: 200ms;         /* Page transition */
--motion-moderate: 300ms;       /* Complex animation */

/* 推荐的缓动函数 */
--motion-standard: cubic-bezier(.2, 0, 0, 1);    /* 标准缓动 */
--motion-enter: cubic-bezier(0, 0, .2, 1);       /* 进入 */
--motion-exit: cubic-bezier(.3, 0, 1, .3);       /* 退出 */
```
