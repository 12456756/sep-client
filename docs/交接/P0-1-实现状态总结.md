## 🐛 已知问题

### 1. TypeScript 类型错误 (不影响运行)

**影响范围**: `pi-host.ts` 和 PoC 脚本  
**优先级**: P1 (不阻塞开发)

**错误列表**:
- `pi-host.ts:85` - `CreateAgentSessionResult` 类型不匹配
- `pi-host.ts:88` - `DefaultResourceLoader` 缺少 `cwd` 和 `agentDir`
- `pi-host.ts:97-104` - `session.on()` 方法不存在（应该用 `session.subscribe()`）
- `poc/*.ts` - 类型断言问题

**解决方案**: 
- 阅读 `pi-coding-agent` v0.83.0 的实际类型定义
- 参考 PoC 脚本中的正确用法
- 修复类型不匹配

### 2. API 响应格式与文档不一致 (已修复)

**问题**: 原交接文档中的类型定义与实际 API 响应不匹配

**已修正**:
- ✅ `ClientInstance.instanceId` → `id`
- ✅ `ClientInstance.displayName` → `name`
- ✅ `InstanceTokenResponse.accessToken` → `instanceToken`
- ✅ 添加 `template` 和 `department` 字段
