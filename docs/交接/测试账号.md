## 注意事项

1. **实例列表返回格式**: 当前返回的实例数据缺少部分字段（`packageRef`, `allowedModels`），与 API 文档不完全一致
2. **设备指纹**: 每次登录会创建新的设备记录，相同 `fingerprint` 会复用设备
3. **Token 有效期**:
   - 通用 accessToken: 1 小时
   - refreshToken: 30 天
   - 实例级 accessToken: 15 分钟

## 快速测试登录 API

```bash
curl -X POST http://localhost:3001/client/auth/login \
  -H "Content-Type: application/json" \
  -d '{
    "email": "<STAFF_EMAIL>",
    "password": "<TEST_PASSWORD>",
    "fingerprint": "test-device-001",
    "platform": "darwin",
    "clientVersion": "1.0.0"
  }'
```

预期响应包含: `accessToken`, `refreshToken`, `user`, `enterprise`
