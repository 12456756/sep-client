## 🔧 架构变化

### Session 生命周期（已调整）

**旧流程**:
```
选择实例 → 进入聊天页 → 创建 session → 发送消息
```

**新流程**:
```
选择实例 → 创建 session → 进入任务板 → 随时执行任务
```

### 任务执行流程（新增）

```
用户创建任务
  ↓
TaskManager.createTask()
  ↓
task.status = 'pending'
  ↓
PiHost.executeTask(taskId)
  ↓
session.prompt(task.prompt)
  ↓
监听事件，更新任务状态:
  - agent_start → running
  - agent_settled → completed
  - agent_end (error) → failed
  - tool_call → waiting_approval
```

### 工具审批流程（已集成）

```
AI 调用工具
  ↓
pi-extension/guard.ts 拦截
  ↓
检查权限 (工作目录/工具类型)
  ↓
需要审批 → 回调 onToolApprovalRequest
  ↓
PiHost 更新任务状态为 waiting_approval
  ↓
等待用户批准/拒绝
  ↓
PiHost 恢复任务状态为 running/failed
```
