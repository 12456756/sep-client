# 对话浏览器会话

## 归属与授权

- `ConversationExecutor` 按企业、成员和任务 ID 管理 `SharedPiSession`。
- `SharedPiSession` 持有 `SharedBrowserOwner`。普通轮次结束、模型切换和员工切换只释放当前 Pi 会话，不关闭浏览器；不同对话不共享浏览器。
- `SharedBrowserOwner` 只保留内置 Playwright MCP 连接。员工专用连接器、Office 和工具授权仍按轮次创建和释放。
- 每轮借用浏览器获得独立租约，旧租约不能继续调用工具。人工接管使用当前轮次的审批回调，不复用前一员工的授权。
- 正在执行或结果不确定的操作不能跨租约继续；取消时先撤销租约，再异步关闭资源。

## 窗口模式

- 首次实际使用时启动独立的有界面浏览器；不连接用户日常浏览器，不持久化登录数据到共享账号目录。
- Windows 通过专用浏览器进程 PID 枚举和隐藏窗口；macOS 通过相同 PID 对应的 `NSRunningApplication` 隐藏或显示。
- 显示和隐藏不重建浏览器，不复制 Cookie 后重载，不重放导航、表单或业务提交。页面内存、标签选择、表单和登录状态留在原页面。
- 无法隐藏时保留原窗口可见并向模型说明，不能静默切换无头浏览器。启动或新窗口创建可能短暂显示，不能保证全程零闪烁。
- 登录接管前必须已经打开目标网页。用户确认后重新读取快照核验登录，不将人工确认直接视为登录或业务提交成功。
- 内置模式以外的显式 MCP 配置保持原有行为。

## 释放入口

- 空闲 30 分钟释放内置浏览器；下轮以实际页面快照为准，不能假定登录仍存在。
- 暂停、取消、优先中断、退出账号及退出客户端撤销浏览器租约并关闭资源。
- `TaskRuntime.releaseTaskResources(taskId, scope)` 是宿主内部生命周期入口，不暴露新的 IPC；删除成功后由服务层回调，按删除时捕获的用户范围释放浏览器和对话缓存。
- 删除失败或任务仍在执行时不释放该任务资源。释放入口使用 `runtime.peek()`，不会为删除动作提前加载 Pi SDK。
- 用户主动关闭浏览器会使旧会话状态失效，不自动伪装成已恢复的空白页面；明确关闭后可重新建立浏览器会话。

## 验证边界

- Windows 需要真实浏览器验证隐藏、显示、页面身份和跨轮次复用。
- macOS 控制路径需要在 macOS 上实机验证；Windows 测试不能替代该验证。
- 网站自己的登录过期、风控或访问权限不在客户端会话共享的保证范围内。
