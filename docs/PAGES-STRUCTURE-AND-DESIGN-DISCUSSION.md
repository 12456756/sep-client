## 🔴 第一优先级 (P1) — 首页 & 员工列表

### 1️⃣ HomePage 分析

**当前结构**:
```
.ent-home
├── .ent-figures (两个统计卡片)
│   ├── .ent-figure (公司员工总数)
│   └── .ent-figure (我拥有的员工)
├── .ent-wall (员工墙)
│   ├── .ent-wall-track (可滚动轨道)
│   ├── .ent-wall-flat (不成环时的平铺)
│   └── 箭头和缩放控制
└── .ent-arrange-bar (派活框 - 当前在底部)
```

**当前问题**:
- ❌ 统计卡片太小 (160-190px)，视觉不突出
- ❌ 员工卡片排列疏松 (大间距)
- ❌ 派活框在底部，容易被忽视
- ❌ 整体信息密度低

**设计目标**:
```
顶部 (35% 高度):
┌─────────────────────────────────────┐
│ 统计卡片（放大到 300-320px）        │
│ • 公司员工总数                      │
│ • 我拥有的员工                      │
│ • 可选：进度条展示                   │
└─────────────────────────────────────┘

中部 (50% 高度):
┌─────────────────────────────────────┐
│ 员工墙（3-4 列紧凑网格）            │
│ ┌─────┐ ┌─────┐ ┌─────┐            │
│ │员工 │ │员工 │ │员工 │            │
│ │卡片 │ │卡片 │ │卡片 │            │
│ └─────┘ └─────┘ └─────┘            │
└─────────────────────────────────────┘

右下 (悬浮):
┌─────────────────────┐
│ 快速派活框          │
│ [输入] [派出]       │
└─────────────────────┘
```

**需要讨论的问题**:
1. ❓ 统计卡片是否需要添加进度条或其他可视化？
2. ❓ 员工卡片在首页是否需要显示更多信息？（当前：头像、名字、状态、工作进度）
3. ❓ 派活框是否改为右下悬浮？还是保留其他位置？
4. ❓ 员工卡片的大小多少比较合适？(当前~180px → 建议~250-280px)

### 2️⃣ EmployeesPage 分析

**当前结构**:
```
.ent-page
├── .ent-toolbar (搜索、筛选、视图切换)
├── .ent-result-note (结果计数)
└── .ent-emp-grid (卡片网格) 或 .ent-emp-list (紧凑列表)
    └── EmployeeCard × N (虚拟滚动)
```

**当前问题**:
- ❌ 卡片尺寸不统一 (响应式导致)
- ❌ 卡片之间间距不规范
- ❌ 信息显示不够详细（缺少技能、权限等）
- ❌ 头像太小 (当前 md 大小)
- ❌ 工具栏布局不够突出

**设计目标**:
```
顶部 (工具栏 - 固定):
┌──────────────────────────────────┐
│ 🔍 [搜索] [筛选] [视图] [范围]    │
└──────────────────────────────────┘

卡片网格 (3 列 → 2 列 → 1 列):
┌─────────────┬─────────────┬──────────┐
│ ┌─────────┐ │ ┌─────────┐ │┌──────┐ │
│ │ 头像    │ │ │ 头像    │ ││头像  │ │
│ │ 80x80   │ │ │ 80x80   │ ││80x80 │ │
│ └─────────┘ │ └─────────┘ │└──────┘ │
│             │             │         │
│ 名字        │ 名字        │名字    │
│ 职位        │ 职位        │职位    │
│ 状态        │ 状态        │状态    │
│ 简介        │ 简介        │简介    │
│ 擅长: 标签  │ 擅长: 标签  │擅长:  │
│ [对话] [详] │ [对话] [详] │[对]   │
└─────────────┴─────────────┴────────┘
```

**卡片信息结构**:
```
┌────────────────────────────────┐
│ [头像 80x80] 名字 [状态徽章]   │  ← 头部：头像+名字+状态
├────────────────────────────────┤
│ 简介文本 (1-2 行)              │  ← 中部：描述
│                                │
│ 擅长: [标签1] [标签2] [+N]     │  ← 技能标签
├────────────────────────────────┤
│ ✓ 已授权 N/M 项  | 上次工作 Xt  │  ← 统计信息
├────────────────────────────────┤
│ [对话按钮] [详情按钮]          │  ← 操作按钮
└────────────────────────────────┘
```

**需要讨论的问题**:
1. ❓ 卡片宽度应该固定为多少？(建议 280px)
2. ❓ 卡片应该显示哪些信息？(名字、职位、状态、简介、技能、授权、上次工作)
3. ❓ 头像大小多少合适？(建议 80x80px)
4. ❓ 是否需要保留"紧凑列表"模式？还是只用卡片视图？

## 🟡 第二优先级 (P2) — 其他页面

### 3️⃣ OrganizationPage 分析

**当前结构**:
```
.ent-organization
├── .org-page-intro (页面说明)
└── .org-workbench
    ├── .org-tree-panel (左侧：组织树)
    │   ├── .org-panel-toolbar (搜索、筛选、缩放)
    │   └── .org-tree-scroll (可缩放、可拖拽的树)
    │       └── .org-tree (节点树)
    │           └── OrganizationTreeNodeView × N (递归)
    └── .org-drawer (右侧：成员详情抽屉)
        ├── .org-drawer-head (头部：头像+名字+状态)
        └── .org-drawer-team (硅基员工列表)
```

**当前问题**:
- ❌ 树状结构复杂，节点卡片样式不统一
- ❌ 连接线和展开/收起按钮交互不明显
- ❌ 工具栏布局混乱 (搜索、筛选、缩放、适应屏幕全混一起)
- ❌ 右侧抽屉员工列表没有卡片化
- ❌ 小屏幕时树状结构无法使用

**设计目标**:
```
页面布局：
┌─────────────────────────────────────┐
│ [搜索框] [部门筛选] [缩放控制]      │  ← 工具栏（分离）
├─────────────────┬───────────────────┤
│                 │                   │
│  组织树          │  成员详情          │
│  (左 40%)       │  (右 60%)         │
│  ┌─────────┐   │ ┌───────────────┐ │
│  │ 公司    │   │ │ 名字  [状态]  │ │
│  │ ├─ 部门 │   │ │ 职位 | 部门   │ │
│  │ │ ├─人1 │   │ │               │ │
│  │ │ └─人2 │   │ │ 可用硅基员工:  │ │
│  │ └─ 部门 │   │ │ [员工卡片]    │ │
│  └─────────┘   │ │ [员工卡片]    │ │
│                 │ └───────────────┘ │
└─────────────────┴───────────────────┘
```

**需要讨论的问题**:
1. ❓ 树状结构是否需要改为其他展现形式？(当前树状是否足够清晰)
2. ❓ 树节点卡片大小多少合适？
3. ❓ 右侧抽屉是否需要改为可扩展面板？
4. ❓ 小屏幕(<768px) 如何处理？(隐藏树？改为模态框？)

### 4️⃣ ArrangeWorkPage 分析

**当前结构**:
```
.ent-arr
├── ModeCards (选择模式：对话式/自动/自己编排)
├── ChatArrange (模式 1：对话式)
├── AutoArrange (模式 2：自动编排)
├── ManualArrange (模式 3：自己编排)
└── RunSettingsDrawer (右侧抽屉：执行设置)
```

**当前问题**:
- ❌ 三个模式卡片并排，小屏幕时拥挤
- ❌ 每个模式的界面复杂度不同，样式不一致
- ❌ 执行设置抽屉可能被覆盖
- ❌ 返回按钮位置不明显

**设计目标**:
```
模式选择:
┌─────────────────────────────────────┐
│ 选择派活方式                        │
├─────────────────────────────────────┤
│ ┌──────────┐ ┌──────────┐ ┌──────┐ │
│ │ 对话式   │ │ 自动编排 │ │自己  │ │
│ │          │ │          │ │编排  │ │
│ └──────────┘ └──────────┘ └──────┘ │
└─────────────────────────────────────┘

模式内容 (以对话式为例):
┌─────────────────────────────────────┐
│ [← 返回] 对话式派活                 │
├─────────────────────────────────────┤
│ 选择员工:                           │
│ ┌─────────┐ ┌─────────┐            │
│ │ 员工    │ │ 员工    │            │
│ │ 卡片    │ │ 卡片    │            │
│ └─────────┘ └─────────┘            │
│                                     │
│ 输入框: [描述工作]                  │
│ [执行设置] [开始]                   │
└─────────────────────────────────────┘
```

**需要讨论的问题**:
1. ❓ 三个模式卡片是否需要改为其他选择方式？(标签页？列表？)
2. ❓ 每个模式的界面大小和布局是否统一？
3. ❓ 执行设置是改为抽屉还是改为模态框？
4. ❓ 员工选择器的卡片大小多少合适？

### 5️⃣ WorkRecordsPage 分析

**当前结构**:
```
.ent-page
├── .ent-toolbar (筛选标签、搜索)
├── .ent-result-note (结果计数)
└── .ent-records (记录列表)
    └── EmployeeRecord × N (可展开的行)
```

**当前问题**:
- ❌ 列表样式单调，没有卡片化
- ❌ 信息密集，展开后信息结构不清晰
- ❌ 筛选标签在小屏幕时超宽
- ❌ 操作按钮 (删除、终止) 不突出

**设计目标**:
```
工作记录卡片化:
┌──────────────────────────────────────┐
│ [工作状态徽章] 工作标题              │  ← 标题行
│ 👥 员工1 · 员工2 | 📁 /path         │  ← 参与者和路径
├──────────────────────────────────────┤
│ 目标: 描述文本...                    │  ← 工作目标
│ 结果: 交付物名称                     │  ← 结果
│ 进度: 已完成 3/5 步                  │  ← 进度
├──────────────────────────────────────┤
│ [查看进展] [查看结果] [更多...]     │  ← 操作
└──────────────────────────────────────┘
```

**需要讨论的问题**:
1. ❓ 工作记录是改为卡片视图还是保留列表？
2. ❓ 卡片应该显示哪些信息？(标题、状态、参与者、目标、结果、进度)
3. ❓ 操作按钮如何放置？(卡片底部？右侧？下拉菜单？)
4. ❓ 搜索和筛选工具栏如何优化？

## 🎨 全局设计规范讨论

### 颜色系统
```
主色: #6366f1 (蓝紫)
辅色: #818cf8 (浅紫)

状态色:
- 成功: #10b981 (绿)
- 警告: #f59e0b (琥珀)
- 危险: #ef4444 (红)
- 中立: #6b7280 (灰)

背景:
- 主背景: #ffffff (白)
- 次背景: #f7f8fc (浅灰蓝)
- 三级背景: #f0f1f8 (浅蓝)

文字:
- 主文字: #20232b (深灰)
- 次文字: #555b6e (灰)
- 三级文字: #858a98 (浅灰)
```

❓ **需要讨论**:
1. 颜色系统是否需要调整？
2. 是否需要添加深色模式支持？

### 间距规范
```
-- 卡片间距: 16px (P1) / 12px (P2)
-- 卡片内边距: 16px (header) / 20px (body)
-- 最小间距: 4px
-- 标准间距: 8px / 12px / 16px / 20px / 24px / 32px
```

❓ **需要讨论**:
1. 间距是否需要调整？

### 圆角规范
```
卡片: 12px
按钮: 8px
输入框: 8px
头像: 10px (正方形) / 50% (圆形)
标签: 6px
```

❓ **需要讨论**:
1. 圆角大小是否合适？

### 阴影规范
```
卡片默认: 0 2px 8px rgba(0, 0, 0, 0.08)
卡片 Hover: 0 8px 16px rgba(0, 0, 0, 0.12)
浮动元素: 0 8px 24px rgba(0, 0, 0, 0.12)
```

❓ **需要讨论**:
1. 阴影强度是否合适？
