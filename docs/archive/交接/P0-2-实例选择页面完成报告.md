## 🎯 实现细节

### 实例选择流程

```
用户登录成功
  ↓
获取实例列表 (GET /client/instances)
  ↓
判断实例数量
  ├─ 0 个 → 显示"暂无可用实例"提示
  ├─ 1 个 → 自动选择并获取 token，跳转到聊天页面
  └─ 多个 → 显示选择页面
      ↓
用户选择实例
  ↓
获取实例令牌 (POST /client/auth/token)
  ↓
保存到 localStorage (lastSelectedInstanceId)
  ↓
回调 onInstanceSelected(instanceId, instanceToken)
  ↓
跳转到聊天页面
```

### 工具审批流程

```
AI 请求执行工具 (bash/write/edit)
  ↓
pi-extension/guard.ts 拦截
  ↓
主进程发送 IPC 事件: pi:tool-approval-request
  ↓
App.tsx 监听事件，显示 ToolApprovalDialog
  ↓
用户选择 (允许/拒绝 或 60s 超时)
  ↓
App.tsx 发送 IPC 响应: pi:tool-approval-response
  ↓
主进程解析响应，返回给 pi-coding-agent
  ↓
工具执行或阻止
```

**类型定义已更新**: `electron/preload.ts` 中的 `getInstances` 返回类型

### 2. POST /client/auth/token

**请求**:
```bash
curl -X POST http://localhost:3001/client/auth/token \
  -H "Content-Type: application/json" \
  -d '{"refreshToken": "<token>", "instanceId": "<id>"}'
```

**响应** (实际格式):
```json
{
  "instanceToken": "eyJhbGc...",
  "expiresIn": 900,
  "instance": {
    "id": "cms6tqk3s001y7q7lpzghjxfk",
    "name": "111",
    "templateId": "demo-emp-skills",
    "status": "ACTIVE"
  }
}
```

**类型定义已更新**: `electron/preload.ts` 中的 `getInstanceToken` 返回类型
